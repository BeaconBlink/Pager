# Pager

## Libraries
- [esp32](https://github.com/espressif/arduino-esp32) @ 2.0.17
- [TFT_eSPI](https://github.com/Bodmer/TFT_eSPI) @ 2.5.43
  (setup as in [documentation](https://www.waveshare.com/wiki/ESP32-S2-Pico#LCD))
- [ReactESP](https://github.com/mairas/ReactESP) @ 2.1.0
- [ArduinoJSON](https://github.com/bblanchon/ArduinoJson) @ 7.0.4

## Settings

Deployment specific settings should be set in `Settings.h` file as specified in `Settings.h.example`.
```bash
cp Settings.h.example Settings.h
```
